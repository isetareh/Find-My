# Requirements and User Stories

## 1. Introduction

Find My is a system for finding lost and found items at the university. Students can use it to report things they have lost or things they have found. They can also search through the reports to see if someone has found their missing item.

The main goal is to make finding lost items easier and save students time.

## 2. Users of the System

The main users of Find My are:

- **Students:** They can report lost or found items and search for items.
- **University Staff:** They can help manage lost and found items at the university.

## 3. Functional Requirements

The system should allow users to:

- **FR-01:** Report an item they have lost.
- **FR-02:** Report an item they have found.
- **FR-03:** Add details about an item, such as its name, description, location, and date.
- **FR-04:** View the list of reported lost and found items.
- **FR-05:** Search for an item using its name or other available details.
- **FR-06:** View more information about a reported item.
- **FR-07:** Follow up on a report to check if there is any update.

## 4. Non-Functional Requirements

The system should also have the following qualities:

- **NFR-01 — Usability:** The system should be simple and easy to use.
- **NFR-02 — Performance:** Searching for items should not take too long.
- **NFR-03 — Privacy:** Users' personal information should be kept private.
- **NFR-04 — Reliability:** The system should save reports correctly so that users can find them later.

## 5. User Stories

### User Story 1: Reporting a Lost Item

As a student, I want to report an item I have lost so that I can have a better chance of finding it.

### User Story 2: Reporting a Found Item

As a student, I want to report an item I have found so that its owner can find it.

### User Story 3: Searching for an Item

As a student, I want to search for lost and found items so that I can check if my missing item has been reported.

### User Story 4: Viewing Item Details

As a user, I want to see the details of an item so that I can check if it matches the item I am looking for.

### User Story 5: Following Up on a Report

As a user, I want to check for updates on a report so that I know if there is any new information about the item.

## 6. Notes

These requirements are our initial ideas for the Find My system. We may change or add some requirements as we learn more about what users need and how the system should work.
