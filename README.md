# Find My 🎒

**A University Lost and Found Management System**

## About

Find My is a university-based Lost and Found Management System designed to help students report, find, and recover lost belongings through a centralized platform.

Students can create lost and found listings, browse and search active items, view listing details, and contact reporters. Staff members can review and manage listings, update their statuses, and remove inappropriate entries.

## Features

**Students**
- Log in using a university account.
- Create LOST and FOUND listings.
- Browse and search active listings.
- View listing details and contact the reporter.
- Mark their own listings as returned.

**Staff**
- View and search all non-deleted listings.
- Mark active listings as returned.
- Soft-delete inappropriate or invalid listings.

## Project Scope

The project focuses on listing management, searching, viewing item details, authentication, and staff moderation.

In-app messaging, automated item matching, notifications, and online ownership verification are not included in the current scope. Physical handover and ownership verification take place outside the system.
