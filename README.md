# Find My

### Project Overview
Find My is a proposed web-based system for managing lost and found items at a university.

Students and university staff can report items they have lost or found. Users can search the registered reports to make it easier to locate missing belongings and follow up on them.

The main goal is to make the lost-and-found process more organized, accessible, and efficient.

### Project Objectives
- Allow users to register lost and found items.
- Help users search for reported items.
- Make the process of finding and following up on missing belongings easier.
